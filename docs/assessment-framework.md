# 外贸独立站实战模拟教学评估体系

## 一、评估理念

### 从"结果评价"转向"能力评价"

| 传统思维 | 正确思维 |
|---------|---------|
| 店铺是否盈利？❌ | 学生是否具备盈利能力？✅ |
| 页面做得好看吗？❌ | 决策逻辑是否正确？✅ |
| 完成度100%吗？❌ | 关键节点决策质量如何？✅ |
| 模拟环境无真实数据 | 过程数据+决策链路可追溯 |

**核心原则**：我们培养的是"能做出正确决策的人"，而不是"能搭建店铺的人"。

## 三、各维度详细评估标准

### 3.1 自主决策能力 (30分)

**核心问题**：学生是否能在关键节点做出合理决策？

#### 评估场景与评分标准

| 决策场景 | 评估指标 | 分值 | 评分标准 |
|---------|---------|------|---------|
| **选品决策** | 市场分析深度 | 6分 | 是否分析了目标市场需求、竞争格局、利润空间？决策依据是否充分？ |
| **定价策略** | 定价逻辑 | 5分 | 是否考虑成本、竞品价格、市场定位？定价是否合理？ |
| **渠道选择** | 渠道匹配度 | 5分 | 广告渠道选择是否符合目标客户画像？预算分配是否合理？ |
| **页面设计** | 转化逻辑 | 5分 | 首页/详情页是否考虑用户旅程？是否有明确的转化引导？ |
| **营销活动** | 活动策划 | 5分 | 活动方案是否完整？时间/力度/预算是否合理？ |
| **预算管理** | 资金规划 | 4分 | 预算分配是否符合业务优先级？是否有应急储备？ |

#### 数据采集点

```typescript
// 系统自动记录
{
  studentId: string,
  decisions: [
    {
      step: 'product_selection',
      timestamp: '2024-01-15 10:30',
      input: { selectedProductId: 'P001', reason: '...' },
      aiSuggestions: [...],  // AI提供的建议选项
      finalDecision: '...',   // 学生的最终决策
      timeSpent: 1200,        // 决策耗时（秒）
      revisions: 2,           // 修改次数
    }
  ]
}
```

#### 评分算法示例

```python
def score_decision_quality(decision):
    score = 0
    
    # 1. 决策依据充分性 (0-2分)
    if decision.reason and len(decision.reason) > 50:
        score += 2  # 有详细的决策理由
    elif decision.reason:
        score += 1  # 有简单理由
    else:
        score += 0  # 无理由直接决策
    
    # 2. 与AI建议的关系 (0-2分)
    if decision.finalDecision not in decision.aiSuggestions:
        score += 2  # 自主决策，非AI建议
    elif decision.aiSuggestionIndex == 0:
        score += 1  # 选择AI首推方案，有思考
    else:
        score += 0.5  # 直接采纳AI建议
    
    # 3. 决策合理性 (0-2分) - 需教师/专家评审
    score += expert_review_score(decision)
    
    return score
```

### 3.2 AI辅助应用能力 (20分)

**核心问题**：学生是否会正确使用AI工具？是否过度依赖？

#### 评估维度

| 维度 | 分值 | 评估内容 | 评分标准 |
|------|------|---------|---------|
| **AI使用策略** | 5分 | 是否在合适的场景使用AI？ | 关键决策点使用AI获取建议，简单任务自主完成 |
| **内容审核能力** | 5分 | 是否对AI生成内容进行审核修改？ | AI生成内容经修改后使用，或用于参考而非直接复制 |
| **决策优化** | 5分 | 是否利用AI优化决策？ | 将AI建议与自身经验结合，做出更优决策 |
| **效率意识** | 5分 | 是否合理利用AI提升效率？ | 在重复性工作使用AI，创造性工作自主完成 |

#### AI耦合度检测机制

```
AI耦合度 = AI生成内容占比 × 内容重要性权重

阈值设定：
- < 30%：低耦合，优秀使用AI辅助
- 30%-60%：中等耦合，合理使用
- > 60%：高耦合，过度依赖，判定为0分
```

#### 评估数据采集

```typescript

      couplingDegree: number, // 耦合度 0-100
    }
  ],
  averageCoupling: number,

}
```

## 四、评估实施流程

### 4.1 实训周期评估节奏

```
Week 1: 市场调研与选品
  └─ 决策评分：选品决策合理性 (6分)
  └─ 数据采集：决策过程记录

Week 2: 独立站搭建
  └─ 决策评分：页面设计转化逻辑 (5分)
  └─ 合规检测：内容/图片版权检查

Week 3: 广告投放
  └─ 决策评分：渠道选择 (5分) + 预算管理 (4分)
  └─ 模拟数据：流量数据生成

Week 4: 运营优化
  └─ 复盘评分：数据解读 (8分) + 问题诊断 (7分)
  └─ 风险应对：第1次风险事件触发

Week 5: 持续优化
  └─ 决策评分：定价策略调整 (5分)
  └─ 复盘评分：优化方案 (6分)

Week 6: 总结复盘
  └─ 复盘评分：复盘报告 (4分)
  └─ 风险应对：第2次风险事件触发
  └─ 能力评估：综合评分
```

4. **AI辅助而非替代**：培养人机协作能力

# 五维能力二级标签方案分析

## 问题背景

### 当前设计
1. **题库系统**：只有5个一级标签（五维能力）
   - 题目字段：`ability: 'decision' | 'ai' | 'analysis' | 'risk' | 'compliance'`
   
2. **评分系统**：需要二级标签（具体能力）
   - 自主决策能力下有6个具体能力：市场分析决策、选品决策、定价策略、渠道选择、物流供应链管理、营销与活动决策
   - 每个具体能力需要独立的得分来源

### 矛盾点
- 评分需要二级标签，但题库只有一级标签
- 专题考试无法精准归类题目到具体能力

---

## 方案对比

### 方案一：添加二级标签（不推荐）

#### 实现方式
```typescript
// 题目数据结构
interface Question {
  id: string;
  type: 'single' | 'multiple' | 'judgment' | 'case' | 'short';
  ability: 'decision' | 'ai' | 'analysis' | 'risk' | 'compliance';
  subAbility?: string; // 新增二级标签
  content: string;
  options?: string[];
  correctAnswer: number | number[];
  difficulty: 'easy' | 'medium' | 'hard';
}
```

#### 二级标签列表（共22个）
```
自主决策能力 (6个)
├── 市场分析决策
├── 选品决策
├── 定价策略
├── 渠道选择
├── 物流供应链管理
└── 营销与活动决策

AI辅助应用 (6个)
├── AI工具选择
├── 内容审核能力
├── 效率优化
├── AI耦合度控制
├── AI视觉策划设计
└── AI文案创意撰写

数据复盘与优化 (4个)
├── 数据采集
├── 数据分析
├── 问题诊断
└── 优化迭代

风险应对 (4个)
├── 风险识别
├── 应对方案制定
├── 客户投诉处理
└── 舆情管理

合规与规则意识 (4个)
├── 平台规则理解
├── 法律法规意识
├── 知识产权保护
└── 数据合规
```

#### 问题分析

**1. AI自动归类难度指数上涨**
```
一级标签（5个）→ AI准确率约95%
二级标签（22个）→ AI准确率约60-70%

原因：
- 二级标签边界模糊（如"选品决策"vs"市场分析决策"）
- 同一题目可能涉及多个二级能力
- 题目内容不足以判断二级标签
```

**示例**：
```
题目：在选择跨境电商目标市场时，以下哪个因素应该优先考虑？
选项：市场规模和增长潜力、竞争程度、物流成本、消费者购买力

一级标签：自主决策能力 ✅ 准确
二级标签：市场分析决策？选品决策？渠道选择？ ❌ 模糊
```

**2. 题库管理复杂度**
- 教师手动标注二级标签 → 工作量巨大
- AI自动标注 → 准确率低，需人工复核
- 题目归类争议 → 同一题目可能属于多个二级标签

**3. 无法对接现有题库**
- 现有题库没有二级标签字段
- 需要全量重新标注（数千道题）
- 第三方题库无法适配

**4. 考试组卷困难**
- 按二级标签组卷 → 题目数量不足
- 部分二级标签题目少于10道
- 难以保证试卷覆盖所有二级能力

### 方案二：维度内平均分配（推荐）

#### 核心思路
**考试只考一级标签（五维能力），维度内的具体能力得分通过其他方式评估**

#### 实现逻辑
```typescript
interface StudentScore {
  // 一级维度得分（来自考试）
  dimensionScores: {
    decision: { exam: 82, practice: 78 };  // 考试82分
    ai: { exam: 75, practice: 72 };
    analysis: { exam: 85, practice: 80 };
    risk: { exam: 78, practice: 75 };
    compliance: { exam: 88, practice: 82 };
  };
  
  // 二级具体能力得分（来自实训任务+专项评估）
  subAbilityScores: {
    decision: {
      '市场分析决策': 82,  // 来自：市场调研实训任务
      '选品决策': 75,      // 来自：选品实训任务
      '定价策略': 76,      // 来自：定价策略实训
      '渠道选择': 79,      // 来自：渠道运营实训
      '物流供应链管理': 73, // 来自：物流配置实训
      '营销与活动决策': 77  // 来自：营销活动实训
    };
    // ... 其他维度
  };
}
```

#### 得分来源重新设计

| 具体能力 | 得分来源 | 说明 |
|---------|---------|------|
| **市场分析决策** | 实训任务 100% | 市场调研报告、竞品分析作业 |
| **选品决策** | 实训任务 100% | 选品方案、利润分析报告 |
| **定价策略** | 实训任务 100% | 定价方案制定、模拟调价 |
| **渠道选择** | 实训任务 100% | 渠道布局决策、资源分配 |
| **物流供应链管理** | 实训任务 100% | 物流商选择、成本优化 |
| **营销与活动决策** | 实训任务 100% | 活动策划、投放决策 |
| **AI工具选择** | 实训+系统 50%+50% | AI使用统计 + 工具选择测试 |
| **内容审核能力** | 实训 100% | AI内容审核实操 |
| **AI耦合度控制** | 系统 100% | AI使用行为分析系统自动计算 |
| **数据采集** | 实训 100% | 数据报表制作、指标提取 |
| **数据分析** | 实训 100% | 数据解读、趋势分析报告 |
| **风险识别** | 实训+考试 60%+40% | 风险案例实训 + 风险识别测试 |
| **应对方案制定** | 实训 100% | 风险应对实训评分 |
| **平台规则理解** | 考试+实训 60%+40% | 规则测试 + 合规操作 |
| **法律法规意识** | 考试 100% | 法律法规专项测试 |

#### 综合评定公式调整
```typescript
// 维度分计算
维度分 = (考试得分 × 考试权重) + (实训平均分 × 实训权重)

// 具体能力得分
具体能力得分 = 实训任务得分 OR 系统自动计算 OR 考试得分

// 最终展示
维度分 = 具体能力得分的平均值
```

#### 优势
1. **题库无需改动** - 维持5个一级标签
2. **AI归类准确** - 一级标签边界清晰
3. **对接现有题库** - 完全兼容
4. **评估更精准** - 实训任务直接对应具体能力
5. **符合教学逻辑** - 具体能力通过实训培养和评估

## 推荐方案：方案二（维度内平均分配）

### 实施步骤

#### Step 1: 调整得分来源配置
```typescript
const fiveDimensions = [
  {
    id: 'decision',
    name: '自主决策能力',
    weight: 35,
    subAbilities: [
      { 
        name: '市场分析决策', 
        scoreSource: {
          practice: { name: '市场调研实训任务', score: 82, weight: 100 }
        }
      },
      { 
        name: '选品决策', 
        scoreSource: {
          practice: { name: '选品方案实训', score: 75, weight: 100 }
        }
      },
      // ... 其他具体能力均为实训来源
    ]
  },
  // ... 其他维度
];
```

#### Step 2: 实训任务映射
为每个具体能力创建对应的实训任务：

| 具体能力 | 对应实训任务 | 评估方式 |
|---------|------------|---------|
| 市场分析决策 | 市场调研报告撰写 | AI评分+教师评分 |
| 选品决策 | 选品方案制定 | AI评分（利润率、可行性） |
| 定价策略 | 定价方案设计 | 模拟销售数据验证 |
| AI耦合度控制 | AI使用行为 | 系统自动计算 |
| 数据分析 | 数据报表解读 | AI评分（准确性） |

#### Step 3: 考试与实训解耦
```
考试（一级维度）→ 维度总体评估
实训（具体能力）→ 具体能力评估

维度分 = 考试得分 × 权重 + 具体能力平均分 × 权重
```

## 总结

### 方案一（添加二级标签）
- ❌ AI归类准确率低
- ❌ 题库管理复杂
- ❌ 无法对接现有题库
- ❌ 组卷困难

### 方案二（维度内平均分配）
- ✅ 题库无需改动
- ✅ AI归类准确
- ✅ 对接现有题库
- ✅ 评估更精准
- ✅ 符合教学逻辑

### 最终建议
**采用方案二**，通过实训任务评估具体能力，考试只评估一级维度。这样既保持了题库的简洁性，又能精准评估学生的具体能力水平。

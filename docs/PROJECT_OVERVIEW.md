# 项目介绍

## 项目概述

**AI时代电商运营决策能力培养平台** 是一款专为中高职、本科院校电商/跨境电商专业设计的云端 SaaS 实训系统。

### 核心理念

从传统的"技能端培训"转向"能力端实训"，培养学生在 AI 时代不可替代的核心能力：

1. **商业决策能力** (35%) - 自主决策、选品、定价、渠道选择
2. **AI辅助应用** (20%) - AI工具选择、内容审核、效率优化
3. **数据复盘能力** (20%) - 数据采集、分析、问题诊断、优化迭代
4. **风险应对能力** (15%) - 风险识别、应对方案、客户投诉处理
5. **合规与规则意识** (10%) - 平台规则、法律法规、知识产权

### 三大覆盖场景

| 场景 | 平台 | 特色 |
|------|------|------|
| **国内电商** | 淘宝/天猫、拼多多、抖音 | 1:1复刻千牛/抖店后台 |
| **跨境平台电商** | Amazon、Shopee、Lazada | 英文界面，跨境运营流程 |
| **外贸独立站** | Shopify、店匠、WooCommerce | SaaS建站平台操作界面 |

## 技术架构

### 前端技术栈

- **框架**: Next.js 16.1.1 (App Router)
- **UI库**: React 19.2.3
- **语言**: TypeScript 5.x
- **样式**: Tailwind CSS 4.x
- **组件**: shadcn/ui (基于 Radix UI)
- **图标**: Lucide React
- **图表**: Recharts
- **表单**: React Hook Form + Zod

### 后端技术栈

- **数据库**: PostgreSQL (通过 Drizzle ORM)
- **ORM**: Drizzle ORM
- **认证**: NextAuth.js (可选)

### 部署方案

- **开发环境**: `pnpm dev` (端口 5000)
- **生产构建**: `pnpm build`
- **生产运行**: `pnpm start`
- **支持部署**: Vercel、Docker、云服务器

## 快速开始

### 环境要求

- Node.js >= 24.x
- pnpm >= 9.0.0
- Git

### 安装步骤

```bash
# 1. 克隆项目
git clone https://github.com/your-username/ecommerce-training-platform.git
cd ecommerce-training-platform

# 2. 安装依赖
pnpm install

# 3. 配置环境变量
cp .env.example .env.local

# 4. 启动开发服务器
pnpm dev

# 5. 访问 http://localhost:5000
```

## 设计特色

### 1:1 平台复刻

平台后台界面 1:1 复刻真实电商平台的视觉风格：

| 平台 | 主题色 | 界面风格 |
|------|--------|---------|

| 拼多多商家版 | 🔴 红色 | 拼多多商家后台 |
| 抖音抖店 |  黑色 | 抖店后台风格 |
| Amazon Seller | 🔵 深蓝 | 英文界面，Amazon风格 |
| Shopee | 🟠 橙色 | Shopee卖家中心 |
| Lazada |  蓝色 | Lazada卖家中心 |
| Shopify | 🟢 绿色 | 英文界面，Shopify风格 |
| 店匠 | 🟣 紫色 | 店匠后台风格 |
| WooCommerce | 🟣 蓝紫 | WooCommerce风格 |

### AI 辅助设计原则

- **AI 提供选项，学生做决策**
- **AI 提供建议，学生承担结果**
- **全流程模拟，零成本零风险**
